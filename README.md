# AZET Sweep community

Questions, ideas and help for AZET Sweep (Android, Windows, Mac and the browser extension).

- **Ask or discuss:** [Discussions](https://github.com/neulketing/sweep-community/discussions)
- **A site is blocked by mistake, or an ad got through:** use "Report" in the app, or https://azet.io/sweep/report
- **Account, payment or anything private:** hello@azet.io — please do not post license keys, email addresses or other personal details here.

Sweep's own source is not in this repository. Product page: https://azet.io/products/sweep
